🐘 Curso de PHP — Fundamentos e Prática
Este repositório é dedicado ao meu aprendizado em PHP, contendo anotações teóricas, resolução de desafios de lógica e exercícios práticos desenvolvidos durante o curso.

📂 Organização do Repositório
O conteúdo está dividido em três pilares principais para facilitar a consulta:

/anotação: Resumos e conceitos fundamentais da linguagem.

/desafios: Problemas complexos que exigem aplicação de lógica avançada.

/exercicios: Práticas rápidas para fixação de sintaxe, estruturas de repetição e condicionais.

🛠️ Tecnologias de Estudo
PHP 8+: Foco nas funcionalidades modernas da linguagem.

Servidor Local: Uso de ferramentas como XAMPP/Laragon para execução dos scripts.

Lógica de Programação: Aplicação de algoritmos em ambiente backend.

🚀 Como Explorar os Exemplos
Certifique-se de ter um ambiente PHP configurado em sua máquina.

Clone o repositório:

Bash
git clone https://github.com/HinoriDev/cursophp.git
Mova as pastas para o diretório raiz do seu servidor local (ex: htdocs).

Acesse via navegador através do localhost/cursophp/.
